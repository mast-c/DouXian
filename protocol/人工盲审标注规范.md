# 药品—疾病关系：人工盲审标注规范 v1

**用途：开发集 21 条重点复核及未来 300 条独立评测。**

本规范以用户已有的 `Claim → Evidence` 文本证据模型为基础。
**文本符合原文 ≠ 药品已经获监管机构批准该适应症。**
审核时必须独立核对药品通用名、剂型、规格、给药途径、
监管地区、上市许可持有人和具体说明书版本。

## 一、审核者先看什么

建议顺序：

1. 药品名称、候选疾病/症状、source_url；
2. 适应症原文与必要的前后章节；
3. 本条候选出现的字符范围，确认没有错配到同名的其他位置；
4. 完整病种、治疗对象/患者条件、否定、病因、给药条件；
5. 原文不足时，标记“证据不足”而不靠常识填补；
6. 需要临床可信关系时，再核验权威药品说明书/监管信息。

双人盲审表故意不包含 Qwen 预测、旧版 AI 标签、事先的风险分类。
两名审核者应各自独立填写后才对照结果。

## 二、分类字段

### `gold_classification`

| 值 | 使用条件 |
|---|---|
| `SUPPORTED_UNQUALIFIED` | 对候选完整目标的直接支持，没有遗漏的重要限制 |
| `SUPPORTED_QUALIFIED` | 原文支持有条件的使用、特定人群、病型、前序治疗等，必须保留限定 |
| `NOT_SUPPORTED` | 对候选关系不支持、明确否定或候选泛化过度 |
| `NON_TARGET_CONTEXT` | 候选疾病仅为患者合并症、背景、给药条件、排除对象等，非关系目标 |
| `INSUFFICIENT_EVIDENCE` | 现有文段/上下文/产品身份不足以做可靠裁决 |

**注意：** “脊椎炎”命中“强直性脊椎炎”，并不支持无条件“治疗一切脊椎炎”；
应保留 `gold_exact_target=强直性脊椎炎`，同时将过宽候选标
`NOT_SUPPORTED` 或根据标注手册记录其条件性的父概念索引，
但禁止直接建为获批的无条件疾病关系。

### `gold_target_type`

允许 `Disease`、`Symptom`、`ClinicalFinding`、
`PatientCondition`、`AdverseEvent`、`Other`。

例如关节痛通常应优先评估是否为 `Symptom`；
某条文本中“伴肾功能不全”通常要判断是否为
`PatientCondition`，而不是治疗目标。

### `gold_relation_type`

限定为 `treatment`、`prevention`、`symptom_relief` 或留空（非正向关系）。

“降低某疾病的并发症风险”不等于“治疗该疾病本身”。
如果原文对同一目标同时支持治疗与预防，可由审核者分开形成不同 Claim；
当前单标签候选可记录多义争议并留待扩展数据模型。

### `gold_polarity`

`positive`、`negative`、`conditional`、`uncertain`。

“非首选，但在某条件下可用”不等于绝对禁止；
相反，“本品不适用于……”必须保持否定关系。

### `gold_qualifiers_json`

使用 JSON 数组，示例：

```json
[
  {"type": "not_first_line", "value": "不作为治疗原发性高血压的首选药物"},
  {"type": "prior_therapy_failure", "value": "噻嗪类药物疗效不佳"}
]
```

`value` 尽可能是 `evidence_quote` 的逐字连续子串。
如果涉及前文“见上述证候者”，应同时记录前文出处；
不能把指示性短语当作已知的具体证候。

### `source_identity_verified`

仅允许 `yes`、`no`、`unknown`。
若 `yes`，必须填写 `regulatory_source_url` 和
`regulatory_label_version`。这表示审核人员提供了可以复核的来源，
**脚本本身不会自动联网确认监管真伪**。

### `annotator_name` 和 `annotator_role`

填写真实审核角色（药师、医生、法务、研究生等）。
只有独立专业审核完成并确认身份，才能在报告中称为专家裁决。

## 三、开发集里应优先关注的例子

以下都只是**已给文段的标注边界示例，不是药物临床建议**：

| 案例 | 需要裁决的重点 |
|---|---|
| 注射用亚胺培南-西司他丁钠 → 脑膜炎 | 原文明确“不适用于”；正向关系应拒绝 |
| 注射用依他尼酸钠 → 肾功能不全 | 原文表述为“伴有肾功能不全”，判断是否只是患者条件 |
| 盐酸二甲双胍缓释片 → 糖尿病 | 原文仅讲“Ⅱ型糖尿病”，不能扩大到所有糖尿病 |
| 苯海拉明薄荷脑糖浆 → 皮肤瘙痒症 | 治疗与症状缓解是否需要区分 |
| 低分子肝素钠凝胶 → 不稳定型心绞痛 | 首先核对剂型、产品身份与来源对应性 |
| 银丹心脑通软胶囊 → 中风后遗症 | “见上述证候者”需恢复上文条件 |

## 四、裁决方式

每条由两位审核者独立填写 `reviewer_A_21_blind.csv`、
`reviewer_B_21_blind.csv`。完成后执行 `review-status`，
检查缺失字段和核心标签分歧。

分歧由第三位专家或有职责的复核人员在独立文件中裁定，
不要自动让其中一人的标签覆盖另一人。

在未获取足够官方说明书或上下文前，可将
`gold_classification=INSUFFICIENT_EVIDENCE`，
而不是为了提升指标填入“接受”。

## 五、禁止的操作

- 不允许因为 Qwen 返回 `accept` 就写成官方适应症；
- 不允许把 `uncertain` 全部当成 `reject` 或失败；
- 不允许修改已封存的 300 条数据来提高模型表现；
- 不允许把医疗用药条件、病种亚型及给药途径全部折叠为无条件 Drug→Disease；
- 不允许从非权威站点复制的说明书摘录直接生成高可信临床知识。
