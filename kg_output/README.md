# kg_output

基础图谱构建结果与审计报告。

| 文件 | 功能 |
| --- | --- |
| `drugs.jsonl` | 药品节点数据。 |
| `source_records.jsonl` | 来源记录数据。 |
| `sections.jsonl` | 说明书栏目数据。 |
| `chunks.jsonl` | 分块后的文档数据。 |
| `interaction_candidates.jsonl` | 药品相互作用候选关系。 |
| `mentions.jsonl` | 实体提及记录。 |
| `build_report.json` | 图谱构建报告。 |
| `integrity_report.json` | 产物完整性检查报告。 |
| `name_cleaning_report.json` | 药名清洗报告。 |
