# 分类驱动的分步图检索

## 解决的问题

过去，分类意图和相互作用意图会生成两个平行目标，但分类图只在纯分类查询时执行。混合问题既未展开同类药物，也未把前一步结果传给相互作用查询，最终退回起始药物的单药资料。

现在通过 `medical_category_discovery.py` 执行依赖计划：起始药物分类 → 同类候选集合 → 独立的具体药物来源关系 → 对方分类核对。使用既有分类索引和医疗图，不新建相互作用事实，不修改 Neo4j 或重建主索引。

## 可复用的查询操作

- “同一大类”按 JSON 一级类别；“同一子类”按二级类别。只说“同类”默认二级，回答明确说明该假设。
- 同类药物枚举，可保留仅存在于分类目录的条目；临床原文查询仅使用有精确 Drug 身份的药物。
- 默认排除起始药物。支持“排除、除了、不包括”等明确药名排除，以及相互作用对象的具体药名约束。
- 同类候选的成分、禁忌、不良反应、注意事项、用途章节关系查询。疾病、症状、人群等明确条件用于过滤来源目标。
- “哪些成分不同”比较本轮原文已提取的成分节点，保留起始药成分引文，不声称掌握完整配方。
- 相互作用双向检索：候选药的原文提及对方，或对方原文提及候选药。提及成分或类别时，要求具体制剂有独立 HAS_INGREDIENT 或 CLASS_MEMBERSHIP_ASSERTION 原文边，分类文件不能代替该证明。
- “其他类别”默认按候选筛选层级比较；若明确说“同一子类的药与其他大类药物”，候选按子类展开、对方按起始药的一级大类排除。同时属于该起始类别的对象不作为排他的跨类示例。

例如以下问题复用同一套操作，不按具体药名写专用分支：

1. 跟阿莫西林胶囊同一大类的其他药，与其他大类药物有没有相互作用？
2. 阿莫西林胶囊同一子类的其他药有哪些？
3. 阿莫西林胶囊同类药有哪些不同成分？
4. 某药同类药中，哪些资料记载了某疾病相关禁忌？

这不是任意自然语言的完整语义规划。类别比较本身、任意聚合/否定约束、完整配方等价以及个体化用药建议不由本功能推断。“没有副作用”“不含某成分”不能用缺少提及边证明，返回具体能力缺口。未识别药名仍走既有澄清流程。

## 证据和结果

每个示例由真实分类边、具体制剂的原文章节边和需要时的成分/原文类别身份边组成。JSON Pointer、文件哈希、原文偏移及来源记录逐边核对；同一药品若使用多条临床边，必须保留同来源记录要求。

同一相互作用陈述不因匹配不同剂型就重复计数。通过成分/类别推到具体制剂的连接，排除给药途径不同或无法确认的组合：明确局部剂型优先识别，其他名称结合该来源记录的用法章节核对。用法一次批量读取，避免每个身份候选重复扫描全部来源。保留否定、尚不明确和适用条件；共享第三药不能证明两药相互作用。

此路径使用独立 evidence_type `category_discovery_source_path`，前端显示真实箭头方向及逐边来源。回答直接展示源文及分类筛选过程，不通过生成模型补写医学结论。成分/类别连接明确标注为线索，未确认具体组合的临床相互作用。原文记载的用量条件是引文，不是个体化用药建议。

起始药物分类有单独引用，后续相互作用未连接成功时仍可显示。Trace 的 category_discovery 记录每步候选数、检索层级、目标过滤、截断和具体缺口，不再用单药相互作用资料替代同类候选的证据。coverage_complete 始终为 false。

## 成本控制

默认最多检查 48 个同类临床候选、2400 条来源边、每个提及目标 96 个身份连接，总证据最多 32000 字符、8 跳。返回路径总数包括起始药分类，仍受调用方 max_paths 限制。SQL 和循环共享最多 3 秒的发现预算；主索引校验/初始化耗时另计并反映在外层 seconds 中。

分类来源核验和主图原文核验不跳过。候选/来源/路径/时间达到上限时明确报告仅为部分结果，不声称全库无相互作用。纯来源展示不调用 Chroma、重排或云端模型，普通临床问答保留原流程。
