# semantic_graph

本地语义图谱工作数据和可视化预览。

| 文件 | 功能 |
| --- | --- |
| `medical_graph.sqlite` | 本地语义图谱索引数据库。 |
| `medical_graph.manifest.json` | 图谱生成清单和数据版本信息。 |
| `path_preview.html`、`path_preview.png`、`path_preview_excerpt.png` | 图谱路径结果的 HTML/图片预览。 |
| `smoke_queries.json` | 图谱检索冒烟查询集。 |
| `disease_pair_smoke.json`、`patient_language_smoke.json` | 疾病配对和患者语言场景的冒烟结果。 |
| `.gitignore` | 忽略临时图谱产物的 Git 规则。 |
